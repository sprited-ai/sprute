One prompt in. Eight directions out.

Sprute is an open-source command-line tool that turns a text prompt or a character image into animated game sprites, facing every direction. It runs on your own GPU.

From a sentence to a sprite set

sprute create character runs all three steps. Each one also works on its own.

  1. Generate a character

    Describe one, or start from an image you already have.

    sprute generate character --prompt "a knight in silver armor" --name knight

  2. Turn it around

    Sprute draws the character facing south, southeast and the rest of the compass, and saves them as one strip.

    sprute turntable character --character knight

  3. Animate it

    Idle, walk and run come with sprute, along with 119 clips from the Quaternius animation library. You can also generate a new motion from a prompt.

    sprute animate character --character knight --motion run
sprute animate character --character knight --motion quaternius/kick

What you need

A CUDA GPU

Tested on NVIDIA cards. Character animation runs on an RTX 5090 with 32 GB of memory.

Python 3.12 or newer

Install from the repository, then sprute setup fetches ComfyUI and the models.

Your own machine

Everything runs locally. Sprute is MIT licensed.

# install
git clone https://github.com/sprited-ai/sprute && cd sprute
uv venv && source .venv/bin/activate && uv pip install -e .
sprute setup

# make a character with idle, walk and run
sprute create character --prompt "a knight in silver armor"
