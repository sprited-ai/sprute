# Sprute Brawl

A top-down arena brawler whose fighters are sprute characters. You fight waves of enemies in eight directions with idle, walk, run, punch, kick, hit, death and victory animations, all generated by sprute from one character image.

## Play

```bash
python3 -m http.server 8765 --directory examples/brawler
```

Open http://localhost:8765.

| Key | Action |
| --- | --- |
| WASD / arrows | Run |
| Shift | Walk |
| J or Z | Punch |
| K or X | Kick |
| R | Restart after a K.O. |

## How the sprites get in

`characters/hero` is character `0001` animated with Quaternius motions (`sprute animate character --motion quaternius/...`).

A sprute animation is a strip: eight direction cells side by side (S, SE, E, NE, N, NW, W, SW), one strip per frame. `pack.py` turns each strip into an atlas the game can index:

- each row is a direction and each column is a frame
- frames are resampled to 12 fps and cells are scaled by half
- `manifest.json` records frame counts, loop flags and the feet anchor

The game picks the row from the fighter's heading and the column from time. Nothing else about sprute leaks into the game code.

```bash
python examples/brawler/pack.py output/quaternius-0001-20261009 --name 0001 --id hero
```

## Add a fighter

On a machine where `sprute setup` has run (the GPU box), from the repo root:

```bash
examples/brawler/make_character.sh knight "a knight in silver armor"
```

This generates the character, its eight directions and the eight motions the game uses, then packs them and adds `knight` to `characters/characters.json`. The first character in that list is the player, and the others become the enemy gang. With only one character, enemies are hue-shifted copies of it.

## Debugging

`?debug` exposes `window.brawl` with `step(seconds)` and `state`, so you can run the simulation from the console without real-time rendering.
